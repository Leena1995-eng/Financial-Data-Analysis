# Personal Fiscal Health & Deficit Attribution Analysis ??

## Project Overview
An end-to-end data analysis project investigating **Lifestyle Inflation** and **Deficit Spending** patterns. This project identifies why spending occasionally outpaces income and provides data-driven recommendations for financial stabilization.

## Tech Stack
* **Python** (Pandas, NumPy) - Data Cleaning & Wrangling
* **Seaborn/Matplotlib** - Data Visualization
* **Jupyter Notebook** - Exploratory Data Analysis

##  Key Insights
* **Deficit Attribution:** Identified 3 critical months (May '18, Jan '19, June '18) where expenses exceeded income by over 100%.
* **Lifestyle Inflation:** Discretionary "Want" spending grew 2x faster than base income during Q2 cycles.
* **Emergency Fund Gap:** The largest single-month deficit ($7,485) would have depleted a standard 3-month safety net by 40%.
